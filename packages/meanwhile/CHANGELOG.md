# Meanwhile release notes

## 0.1.0 - 2026-11-05

- Home -> Meanwhile lists your Circles. A Circle has a cast, a setting, linked chats, a pace and a model. Its clock runs at x1 or x24, pauses, or takes a set time.
- A timer or opening a linked chat makes the Circle catch up. Each day is one model call with events, diary lines and hooks. A daily call limit applies.
- A character brings a hook up in a linked chat once. "Pick up this thread" brings it up now.
- Fast forward 1 to 7 days; it shows the model calls first.
- Big events wait in "Waiting for you". Plans from chat become promises that the next day honours.
- "Character status" (off by default) writes what a person does now to their chat. It runs at x1 only.
- A Home card lists up to 3 new hooks.
- "Surprise mode" hides news until a character tells you.
- Circle chips, a cast row and tabs for Today, Diary, Phone, Paper, Plans and Timeline. Plans has promises and "Nudge", which plans one event you ask for.
