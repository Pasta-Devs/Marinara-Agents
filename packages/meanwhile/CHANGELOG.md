# Meanwhile release notes

## 0.1.0 - 2026-11-05

- Home -> Meanwhile lists your Circles. A Circle has a cast, a setting, linked chats, a pace and a model. Each Circle has its own clock: run it at x1 or x24, pause it, or set the date and time.
- A timer or opening a linked chat makes the Circle catch up. Each finished Circle day gets one model call that writes events, a diary line per character and a hook. A daily call limit applies (default 12).
- A character brings a hook up in a linked chat once. "Pick up this thread" brings it up now.
- Fast forward 1 to 7 days or up to 168 hours. It shows the model calls first and has a cancel button.
- Big events wait in "Waiting for you": accept, veto or edit them. Plans that characters state in chat become promises that the next day honours.
