# Meanwhile release notes

## 0.1.0 - 2026-11-05

- Home -> Meanwhile lists your Circles. A Circle has a cast, a setting, linked chats, a pace and a model. Each Circle has its own clock: run it at x1 or x24, pause it, or set the date and time.
- A Circle needs a model before it can run. A timer wakes every 5 minutes. A Circle catches up when you open the tab, when a linked chat has new messages, or every 6 hours if you turn on the background switch.
- Each finished Circle day gets one model call. It writes the day's meetings, a diary line per character and a hook: something the character wants to tell you. Big events wait for your OK.
- A character brings a hook up in a linked chat once. "Pick up this thread" makes the next reply bring it up now.
- Each Circle has a daily limit of model calls (default 12). At the limit the card says "Paused: daily limit reached".
